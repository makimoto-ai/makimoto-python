# makimoto-kawa

*Last updated: 2026-08-26*

Official Python SDK for Kawa, Makimoto's transcription API.

This is the maintained, typed client: `pydantic` response models, structured exceptions, and a tested, versioned release process, built on top of the same API as the reference client in the main `kawa` repo.
